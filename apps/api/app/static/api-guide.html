OpsMind AI API 使用说明

这里说明后端 API 的作用、调用方式和主要接口。普通值班人员应使用中文业务工作台， 不需要直接阅读本页。

打开中文业务工作台 打开交互式 Swagger 调试页 查看 OpenAPI JSON
API 文档是给开发人员、测试人员和系统集成方使用的，不是日常事故处置页面。 日常使用请打开业务工作台：http://localhost:8080。

这个 API 负责什么

前端工作台通过 API 完成事故创建、知识检索、AI 调查、审批和审计。

事故管理创建事故、查询列表、更新状态和负责人。
AI 调查检索知识证据、生成故障假设和处置建议。
治理审计人工审批、权限校验和操作日志查询。

调用步骤

  1. 打开业务工作台，或使用演示账号登录。
  2. 调用登录接口，获取 access_token。
  3. 后续请求在 Authorization 请求头中携带 Bearer 令牌。
  4. 根据业务页面需要调用事故、知识、调查或审批接口。

PowerShell 登录示例

$login = Invoke-RestMethod -Method Post `
  -Uri "http://localhost:8000/api/v1/auth/login" `
  -ContentType "application/json" `
  -Body '{"organization_slug":"acme-cloud","email":"admin@opsmind.local","password":"OpsMind!2026"}'

$headers = @{ Authorization = "Bearer $($login.access_token)" }
Invoke-RestMethod -Uri "http://localhost:8000/api/v1/system/overview" -Headers $headers

主要接口

方法路径用途权限
POST/api/v1/auth/login使用邮箱和密码登录公开
GET/api/v1/system/overview获取运营总览指标所有登录用户
GET/api/v1/incidents查询事故列表所有登录用户
POST/api/v1/incidents创建事故管理员、响应者
PATCH/api/v1/incidents/{id}更新事故状态和负责人管理员、响应者
POST/api/v1/incidents/{id}/investigations发起 AI 事故调查管理员、响应者
POST/api/v1/knowledge/search检索处置手册和复盘证据所有登录用户
POST/api/v1/knowledge/documents新增知识文档管理员
GET/api/v1/approvals查询人工审批队列所有登录用户
POST/api/v1/approvals/{id}/decision批准或驳回处置建议管理员、响应者
GET/api/v1/audit/events查询审计日志所有登录用户

常用字段说明

字段中文含义
public_id对外展示的事故编号，例如 INC-2026-1042
severity事故等级：sev1 至 sev4
status事故状态：待处理、调查中、已缓解、已解决
signals延迟、错误率、连接池等运行信号
hypothesesAI 生成的故障假设和置信度
evidence支撑故障判断的知识证据片段
approval_required该处置是否必须经过人工审批
