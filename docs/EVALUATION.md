# AI 效果评测

## 评测目的

OpsMind AI 使用固定 Golden Set 检查最不能退化的能力：

- 能否检索到正确的处置文档。
- 是否包含预期的故障原因。
- 每个故障假设是否引用真实检索证据。
- 中高风险建议是否全部要求人工审批。

## 执行方式

```powershell
cd apps/api
.\.venv\Scripts\python.exe -m app.evaluation
```

当总通过率低于 80% 时，命令会以非零状态退出。CI 会通过 `pytest` 执行同一套评测。

## 当前评测集

`apps/api/app/eval/golden_cases.json` 包含 5 个场景：

1. 灰度发布后结算延迟。
2. 支付渠道超时。
3. 搜索索引复制延迟。
4. 结算数据库连接池耗尽。
5. 发布回滚治理。

## 指标

| 指标 | 含义 |
| --- | --- |
| 检索命中率 | 预期文档是否出现在检索结果中 |
| 关键词命中 | 分析结果是否包含预期故障原因 |
| 证据覆盖率 | 假设是否都引用真实检索证据 |
| 审批策略通过率 | 中高风险建议是否全部要求审批 |
| 场景通过率 | 单个场景是否全部检查通过 |

当前结果：

- 总场景数：5。
- 通过数：5。
- 证据覆盖率：100%。
- 审批策略通过率：100%。

## 后续评测方向

- 扩大企业知识库并要求 recall@k 和 MRR。
- 评估引用精确率和声明级事实一致性。
- 增加提示词注入和高风险处置红队样例。
- 统计值班人员采纳率和纠正率。
- 记录模型延迟、Token 成本和缓存收益。
- 持续执行租户隔离和权限回归测试。
