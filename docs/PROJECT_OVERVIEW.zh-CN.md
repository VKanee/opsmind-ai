# OpsMind AI 项目说明

## 一句话说明

OpsMind AI 是一个“企业线上事故处理工作台”：帮助运维团队把事故信息、处置手册、
历史复盘和 AI 分析集中到一个页面，并确保所有高风险操作都经过人工审批和审计。

## 它解决什么问题

例如，公司的支付接口突然变慢：

1. 监控系统发现错误率和延迟升高。
2. 值班人员创建事故，填写服务名称、严重程度和监控信号。
3. 系统自动搜索内部处置手册、支付服务依赖和历史复盘。
4. AI 生成几个可能的故障原因，并列出每条原因对应的证据。
5. AI 建议限流、扩容或回滚，但不会直接执行。
6. 值班人员审核后批准或驳回建议。
7. 所有调查和审批过程都记录在审计日志里。

## 可以做什么

- 管理和跟踪事故。
- 查看事故等级、状态和持续时间。
- 搜索企业内部处置手册和复盘资料。
- 发起 AI 根因分析。
- 查看 AI 故障假设、置信度和证据来源。
- 审核 AI 提出的生产处置建议。
- 查看用户、AI 和审批操作记录。
- 用固定评测集检查 AI 分析是否退化。

## 目标人群

### 直接使用者

- SRE。
- 值班工程师。
- 事故指挥者。
- DevOps 和平台工程团队。

### 间接使用者

- 技术负责人：查看事故状态和审批记录。
- 安全与审计人员：检查生产变更是否被正确审批。
- AIOps / LLMOps 团队：继续接入模型、监控和企业系统。
- 面试官和招聘方：查看完整的企业级 AI 项目实现。

## 主要页面怎么看

### 运营总览

查看当前有多少事故、多少待审批操作、知识库规模和证据覆盖率。

### 事故中心

查看和创建事故。点击事故后进入事故处置工作台。

### AI 根因分析工作台

点击“开始 AI 调查”或“重新分析”后，会显示：

- 事故摘要。
- 排序后的故障假设和置信度。
- 检索到的证据片段。
- 建议的诊断和处置步骤。
- 哪些操作需要人工审批。

### 知识库

保存处置手册、服务文档、复盘报告和制度规范。AI 调查会从中检索证据。

### 审批中心

批准或驳回 AI 提出的生产变更建议，并填写审批说明。

### 审计日志

查看谁在什么时间创建事故、进行 AI 调查、批准或驳回操作。

## 它不是什么

- 不是普通聊天机器人。
- 不会自动重启数据库或修改云资源。
- 不替代 Prometheus、Grafana、PagerDuty 等监控告警系统。
- 当前演示版本没有接入真实企业员工账号。

## 业务页面和 API 文档有什么区别

- 业务页面：`http://localhost:8080`，给值班人员和普通用户使用。
- 中文 API 使用说明：`http://localhost:8080/docs`，给开发人员理解后端接口。
- Swagger 调试页：`http://localhost:8080/swagger`，给开发人员直接发请求调试。

普通使用者只需要打开业务页面，不需要使用 API 文档。

## 为什么需要 Docker

Docker 把三个部分打包运行：

- Web 前端：中文操作界面。
- API 后端：事故、AI 调查、审批和审计逻辑。
- PostgreSQL 数据库：保存事故和知识数据。

这样不需要手动安装数据库和配置 Python、Node 环境，也能做到一条命令启动、
一条命令停止。
